# EDA Task 5 – Healthcare Data Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a healthcare dataset using Python. The dataset is analyzed to understand patient information, admission details, medical conditions, billing amounts, and hospital stay duration.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / Google Colab

## 📂 Dataset

The project uses a healthcare dataset containing information such as:

* Age
* Gender
* Medical Condition
* Medical Code
* Admission Type
* Date of Admission
* Discharge Date
* Billing Amount

## 🔍 Analysis Performed

The notebook includes the following analysis:

1. Loaded the healthcare dataset using Pandas.
2. Displayed the first few records of the dataset.
3. Checked the dataset shape and information.
4. Generated descriptive statistics.
5. Examined the dataset columns.
6. Checked for missing values.
7. Handled missing values in the `Medical_Code` column.
8. Cleaned the `Admission_Type` column.
9. Analyzed admission type frequencies.
10. Converted admission and discharge dates into datetime format.
11. Extracted year, month, and day from admission dates.
12. Calculated the number of hospital stay days.
13. Analyzed billing amount statistics.
14. Calculated average patient age for each medical condition.
15. Compared medical conditions based on gender.
16. Visualized admission types using a bar chart.

## 📊 Key Features

* Data cleaning and preprocessing
* Missing value handling
* Date and time analysis
* Statistical analysis
* Grouping and aggregation
* Cross-tabulation
* Data visualization

## ▶️ How to Run

1. Download or clone this repository.
2. Open `EDA_Task5.ipynb` using Jupyter Notebook or Google Colab.
3. Make sure the healthcare CSV dataset is available in the required location.
4. Run the notebook cells sequentially.
